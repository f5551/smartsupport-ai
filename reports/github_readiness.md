## الاختبارات المحلية

أُجري فحص توزيع الأسرار دون كشف قيم: `145` ملفًا و`0` finding. كما نجح اختبار `.gitignore` المحدد.
آخر pytest كامل بعد تغييرات التجهيز: `RUN_LIVE_OPENAI=0 .venv\Scripts\python.exe -m pytest -q` — **325 ناجحًا، 0 فاشل، و2 متجاوزان**. المتجاوزان: اختبار OpenAI المدفوع واختبار صلاحيات Linux الذي يتطلب runner Linux. لم ينفذ أي طلب API مدفوع. لا يمكن تنفيذ GitHub Actions عن بعد قبل وجود مستودع ورفع مصرح به.

## الموانع والخطوات التالية

1. لا يمكن إتمام تحقق “المتتبّع في Git” قبل إنشاء مستودع Git؛ الماسح استخدم index مؤقتًا لاختبار قواعد `.gitignore` دون تهيئة أو تغيير المجلد.
2. إنشاء مستودع GitHub عام ثم رفع المشروع يحتاج طلبًا منفصلًا؛ لم يتم هنا. بعده يجب مراجعة محتويات أول commit والـActions على GitHub قبل إعلان اجتياز CI.
3. النشر العام ورابط العرض يحتاجان طلبًا منفصلًا واختبار health والعزل على Render. النشر التلقائي معطل بالإعداد الحالي.
4. يوصى بتثبيت Actions إلى commit SHAs قبل استخدام workflow كضابط أمني طويل الأمد.

لم تُحذف سجلات الكابستون، ولم يتغير أي سجل JSONL، ولم يُنشر المشروع.
