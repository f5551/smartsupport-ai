## 1. هيكل الرفع

```text
README.md                         آخر حالة صادقة وتعليمات التشغيل
agent_spec.md                     المواصفات المختصرة
cost_analysis.md                  عينات التكلفة المنفصلة والحجز المجهول
*.py / ui/ / assets/              التنفيذ وموارد الواجهة
tests/                            اختبارات الوحدات والتكامل والأمان
requirements.txt / .github/       الاعتماديات وCI
.streamlit/ / render.yaml         الإعدادات فقط، دون أسرار أو نشر

traces/                           سجلات الكابستون الثلاثة
reports/README.md                 فهرس التقارير
reports/final/README.md           نقطة دخول للحالة النهائية الحالية
```

أُنشئت فهارس فعلية داخل `reports/final/` و`reports/history/`. تُركت التقارير الأصلية في أماكنها لأن نقلها يغيّر المراجع والاختبارات. لا توجد نسخ جديدة من محتويات تلك التقارير؛ الفهارس روابط وتصنيف فقط. الاسم «final» في تقرير قديم لا يمنحه صلاحية وصف النسخة الحالية.

- الشيفرة والاختبارات والاعتماديات وCI وإعداد Render والموارد المحلية وملفات seed/FAQ الاصطناعية.

- `traces/success_1.jsonl` و`traces/near_failure_recovery.jsonl` و`traces/explicit_failure.jsonl` دون تعديل؛ OpenAI فيها محاكى وMCP فعلي.
- نتائج TASK 08 الحية وusage والتكلفة والسجلات الخمسة. أُضيفت استثناءات ضيقة في `.gitignore` لهذه السجلات الخمسة تحديدًا بعد قراءة JSONL وفحصها: لا حقول حساسة محظورة على المستوى الأعلى، ولا نتائج لأنماط الأسرار. تبقى بقية سجلات التشغيل مستبعدة.
- `runner.py` و`guard.py` المصححان ونسختاهما `*.original.py` داخل دليل TASK 08؛ النسخ الأصلية أدلة تاريخية، وليست نسخ SQLite احتياطية.
- مواصفات الوكيل محفوظة في `agent_spec.md` فقط. حُذفت مخرجات PDF وHTML وصورة إثبات الطباعة بطلب المستخدم؛ حُفظت اختبارات فحص PDF العامة ومعالجته في فاحص الأسرار، فلا يعتمد الفحص على وجود نسخة الطباعة في المستودع.

## 7. نتائج التحقق

- `git diff --check`: اكتمل برمز خروج 0 دون أخطاء؛ تحذيرات LF/CRLF إن ظهرت لا تمثل فشل whitespace.
- كان فحص الإصدار يفشل بـ`UnicodeDecodeError` في لقطة التنظيم الأولى، ثم اجتاز الفحص بعد إصلاح معالجة PDF مع إبقاء الملف؛ حذف مخرجات الطباعة اللاحق تنظيف بطلب المستخدم وليس بديلًا عن إصلاح الفاحص.
- نتيجة ماسح الأنماط لا تضمن غياب كل أنواع الأسرار؛ تبقى مراجعة الصور والخطوط مطلوبة. يُفحص أي PDF مستقبلي باستخراج نصه أو يُسجّل فشل واضح، ولا يُتجاوز بصمت.
- أُبقيت قواعد SQLite والحجز القديم `$0.002445 unknown` والأدلة التاريخية الأصلية دون تعديل. لا تغيير في Agent أو MCP أو بيانات المتجر.
