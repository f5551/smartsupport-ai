# اختبار قبول واجهة SmartSupport AI

تاريخ الاختبار: 2026-11-04

## النطاق والبيئة

- Streamlit محلي على `http://127.0.0.1:8503/`.
- وضع `Demo` مع Fake OpenAI وMCP الحقيقي وبيانات SQLite اصطناعية معزولة في `.runtime/ui-reference-preview`.
- لم يُرسل أي طلب OpenAI مدفوع، ولم تُستخدم قواعد التشغيل أو بيانات عملاء حقيقية.
- الحساب المستخدم للاختبار حساب اصطناعي موجود مسبقًا؛ لم تُعدّل حسابات الإنتاج أو نظام المصادقة.

## مصفوفة القبول

| السيناريو | النتيجة | الدليل |
|---|---|---|
| تسجيل الدخول | PASS | ظهرت مساحة الحساب المصادق عليه، مع `reference-review` و`demo_customer_001`، دون اختيار `customer_id` من الواجهة. |
| تسجيل الخروج | PASS | عاد المتصفح إلى شاشة تسجيل الدخول وأزيلت مساحة العميل. |
| المحادثة وإرسال رسالة | PASS | زر سؤال الشحن أنشأ رسالة مستخدم وإجابة عربية نهائية. |
| اختيار أداة MCP | PASS | ظهرت نتيجة `search_faq` ومصدر الاستعلام عبر MCP؛ المهمة أكملت بـ`final_answer`. |
| صفحة الطلبات | PASS | ظهرت صفحة بحث رقم الطلب مع رسالة توضح أن النتيجة مرتبطة بالحساب الحالي. |
| صفحة التذاكر | PASS | ظهرت متابعة التذاكر ونموذج طلب الدعم الجديد. |
| طلب الموافقة | PASS | ظهرت بطاقة «موافقة إنشاء تذكرة» للطلب `DEMO-1002` مع وصف العملية وزري التأكيد والإلغاء. لم يتم التأكيد ولم تُنشأ تذكرة. |
| إلغاء عملية الكتابة | PASS | زر «إلغاء العملية» أعاد النموذج وأظهر حالة `cancelled` دون كتابة. |
| استعادة المحادثة بعد تحديث الصفحة | PASS* | بعد تحديث المتصفح عاد التطبيق إلى تسجيل الدخول، وبعد تسجيل الدخول بالحساب نفسه عادت محادثة الشحن وسجل طلب الدعم السابق. |
| RTL وعرض الجوال | PASS | عند عرض 390px: `direction=rtl`، و`documentWidth=390` يساوي `innerWidth=390`، بلا تمرير أفقي. |
| الوضع الداكن | PASS | تم تفعيل Dark من قائمة Streamlit، وبقيت المحادثات والبطاقات والـRTL مقروءة. |

`PASS*`: الاستعادة تتطلب مصادقة الحساب مجددًا بعد تحديث كامل للصفحة؛ لا يحتفظ التطبيق برمز دخول في URL أو JavaScript/LocalStorage، وهو سلوك مقصود لتقليل مخاطر تسريب الرموز. بعد المصادقة تستعاد المحادثة الدائمة من SQLite للحساب نفسه.

## الحكم

الواجهة **جاهزة وظيفيًا للقبول المحلي** ضمن وضع المحاكاة الآمنة. القيد الوحيد المقصود هو أن تحديث الصفحة الكامل يتطلب تسجيل الدخول من جديد قبل استعادة المحادثة؛ لم نضع رمز الجلسة في المتصفح لتجاوز هذا القيد. لا توجد أخطاء واجهة مثبتة تستلزم تعديلًا إضافيًا.
