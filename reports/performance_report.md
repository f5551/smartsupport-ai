# SmartSupport AI — تقرير الأداء والاستقرار

تاريخ التدقيق: **2026-11-03**. Windows / Python 3.13.7؛ لا طلبات OpenAI مدفوعة جديدة ولا بيانات عملاء حقيقية. شُغلت الحزمة قبل انقطاع رصيد مساحة العمل، واكتملت نتائجها المحفوظة؛ راجع `run_finished_utc` في [JSON الأصلي](evidence/performance_results.json). أُعيد حساب percentiles من العينات أثناء استكمال التدقيق.

## المنهج والأدلة

- [حزمة إعادة التنفيذ](evidence/performance_harness.py)، [خادم حقن الأعطال الاختباري](evidence/reliability_fault_mcp.py)، [نتائج الاستقرار والحمل](evidence/performance_results.json)، [فحص استنفاد الزوار](evidence/reliability_capacity_results.json).
- بدأت عينات الحمل من `WebBackend` الحقيقي ووصلت إلى Agent و MCP stdio وقواعد SQLite مؤقتة. المزوّد `DemoOpenAI`/Fake فقط. ترفض الحزمة إنشاء عميل مدفوع.
- الزيادة محافظة: **1 ثم 2 ثم 4 جلسات**؛ في كل مستوى موجة باردة تشمل بدء العامل، ثم موجة دافئة على العمال أنفسهم. الحد 4 يطابق أقصى `worker_limit`، وليس استكشافًا لحمل الانهيار.
- زمن العينة هو wall-clock حول عملية طبقة التشغيل، وليس زمن استدلال نموذج حي. قد يتداخل العمل مع اختبارات محلية أخرى؛ Windows واحد وعينات صغيرة لا تمثل إنتاجًا أو أجهزة المستخدمين أو Linux.
- حساب p50/p95 بطريقة **nearest-rank**: القيمة المرتبة رقم `ceil(p*n)`، وليس استيفاءً خطيًا. لهذا قد تكون p95 هي القيمة العظمى مع هذه الأحجام الصغيرة.

## تكلفة وزمن التشغيل الحقيقي السابق

أُعيدت قراءة `traces/live_success_1.jsonl` دون تغييره: [تحقق مستقل](evidence/cost_verification.json). النموذج الفعلي `gpt-5.4-mini-2026-03-17`، طلبان، إدخال 1056، إخراج 72، cached0، و`final_answer` مع `search_faq` ناجحة وإرسال ناتجها إلى النموذج.

الأسعار المسجلة في `pricing.json` لفئة default، والمصدر [OpenAI الرسمي](https://developers.openai.com/api/docs/models/gpt-5.4-mini)، بتاريخ تحقق 2026-11-03: **0.75/0.075/4.50 USD لكل مليون إدخال/إدخال مخزّن/إخراج**. الحساب المعاد بـ Decimal:

```text
(1056 * 0.75 + 0 * 0.075 + 72 * 4.50) / 1_000_000 = 0.001116 USD
0.001116 / 0.02 * 100 = 5.58% من ميزانية المهمة
```

هي تكلفة **مهمة واحدة فقط**، وليست متوسط جميع المهام أو عدة مهام فعلية، ولا فاتورة نهائية تشمل الضرائب/خصومات الحساب. لا تُجمع مع أرقام Fake.

من timestamps وأحداث السجل نفسه: مدة المهمة **9558.439ms (n=1)**، وطلبي النموذج 5445 و 4051ms **(n=2)**، و MCP19ms **(n=1)**. [أدلة المدة](evidence/performance_prior_live_metrics.json). لا ننشر p95 لاستدلال الإنتاج من هاتين النقطتين ولا نبني SLA عليهما.

## الميزانية والتشغيل

`Agent._request` (`agent.py:263`) يوقف الدورات حسب max_turns ويحسب حجزًا قبل الطلب، ثم يسوي من usage. SDK retries=0؛ التطبيق يسمح بإعادة 429 بحد أقصى مرة واحدة وفق الإعداد، داخل سقف 8 دورات، وليس إعادة غير محدودة. أخطاء الاتصال والمهلة توقف المهمة. غياب usage يبقي الحجز ويجعل التكلفة الكلية مجهولة. التقدير ببايتات UTF-8 مع هامش ليس سقف فاتورة رياضيًا.

النشر الحالي `/tmp/smartsupport-ai` في `render.yaml`، دون نسخ احتياطي/استرجاع موثق ومختبر، و`/_stcore/health` فحص حياة الواجهة لا صحة MCP أو DB أو مزوّد النموذج. لا يوجد قياس موزع، تنبيه SLO، أو مسار دائم لاستعادة المهام والمصالحة. Linux CI ملف موجود فقط؛ لم يُنفذ runner Linux في هذه المراجعة.

## ما يلزم قبل حمل تجاري

معالجة سجلات الزوار المنتهية، ثم مخزن دائم وربط سياق موثوق قابل للاستعادة، وسجل idempotency/مصالحة للكتابة، ومراقبة وتنبيهات. بعدها اختبارات Linux واستعادة backup وفشل deploy/rollback وحمل واقعي أطول بملف بيانات متفق عليه. لا تتنبأ هذه العينة الصغيرة بسعة الإنتاج.
