## فجوات ومخاطر متبقية

1. **النسخ الاحتياطي:** لم يُعثر على تنفيذ أو نسخة تاريخية سليمة في checkout أو refs المحلية أو نسخ Desktop المفحوصة؛ لذلك أضيف `backup_manager.py` واختباراته في استكمال المرحلة الخامسة بتاريخ 2026-11-04. اختبارات النسخ العشرة نجحت، وpytest الكامل 357/357 دون فشل. النسخ والاستعادة تغطي كل قاعدة منفردة عبر SQLite Backup API مع manifest وبصمات وفحص سلامة. لا توجد ذرّية لمجموعة قواعد المتجر والموافقات والجلسات والتكلفة. النتائج التفصيلية في `phase5_backup_verification.md`.
2. **التخزين على Render مؤقت:** `render.yaml` يحدد `SMARTSUPPORT_WEB_DATA_DIR=/tmp/smartsupport-ai` والخطة Free. قد تضيع الجلسات والذاكرة والتكلفة والسجلات عند إعادة التشغيل؛ لا ضمان دوام.
3. **المصادقة ليست إنتاجية:** حسابات اختبار محلية بكلمات مرور مجزأة وجلسات خادمية، بلا OIDC أو MFA أو دورة حياة هوية إنتاجية. لا تستخدم بيانات عملاء حقيقية.
4. **دليل النموذج الحي محدود:** توجد مهمة واحدة حية فقط؛ التقييم الحالي 30 حالة FakeOpenAI. اختبار OpenAI الحي متجاوز عمدًا، ولم يُنفذ طلب مدفوع.
5. **التحقق المحدود للمنصة:** اختبار Linux متجاوز على Windows. إعداد GitHub Actions موجود لكنه لم يُشغّل في هذا التحقق؛ لم يُفحص آخر run شبكيًا.
